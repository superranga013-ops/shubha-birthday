# Shubha Birthday Surprise 🎂

## Run locally
1. Install Node.js.
2. In this folder run:
   npm install
   npm start
3. Open http://localhost:3000

## Heroku
Create a Heroku app, then deploy this folder/repository. Heroku will use the included `Procfile`.

## Music
The site is already wired for `song.mp3`. Put a legally obtained copy of your chosen song in the project root's `public/` folder and name it `song.mp3`.
